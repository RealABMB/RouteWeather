Software Used

RouteWeather is powered by two APIs. This page serves as a citation for those two APIs.

Mapbox API

Mapbox is at the route of Routeweather. The API provides mapping along with navigation, POIs and polyline.

Mapbox: https://www.mapbox.com/

OpenWeatherMap API

OpenWeatherMap API is used to retrive weather information on desired locations.

OpenWeatherMap: https://openweathermap.org/
